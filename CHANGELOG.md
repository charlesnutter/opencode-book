# Changelog

Editions of the book. Format follows [Keep a Changelog](https://keepachangelog.com);
versioning is described in [documentation/05-releases.md](documentation/05-releases.md).

**This tracks the book, not the generator.** The tool's version lives in
`pyproject.toml` and moves independently — an upstream docs change produces a
new edition with no code change at all.

Each entry's "Changed" lines are proposed by `scripts/changelog.py`, which
diffs chapter build stamps between tags and attributes each change to its
cause: upstream docs moved, a prompt was edited, or a model was swapped.

### Known limitations

- **Seven of eight chapters are mock output**, generated by
  `tests/mock_server.py` to exercise the pipeline. They are ~25 words of
  placeholder text, not writing.
- **Chapter 05 was written by hand**, served through `tools/replay/server.py`,
  not produced by a local model. See
  [documentation/02-poc-replay-process.md](documentation/02-poc-replay-process.md).
- **No local model has run yet.** That remains the central untested assumption
  (gap G0).
- **Markdown only.** EPUB and PDF are not built — `publish/` has never been run
  against generated chapters (gap G5). The release workflow has the pathway
  wired but gated off.
- `voice/exemplars.md` still holds placeholder samples, so tone is borrowed.

`scripts/changelog.py` flags all seven short chapters and exits non-zero. That
is the guard working, not a failure.
